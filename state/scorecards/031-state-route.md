# 031 State Route

- Status: VALIDATED
- User fit: 5/5 — Unityを含むゲーム制作の画面・ゲームモード・進行状態の設計レビューに直結
- Revenue / hours saved: 3/5 — 状態遷移図を目視確認して進行不能候補を探す作業を1回15〜30分短縮する仮説
- Differentiation: 4/5 — 未到達だけでなく、任意の終了状態へ到達不能なルート、非終了の行き止まり、未定義参照を同時監査
- Cost to validate: 5/5 — 静的ブラウザアプリ、外部依存なし
- Reversibility / downside: 5/5 — ローカル処理のみ。実行時条件を再現しない限界を明記
- Time to evidence: 5/5 — サンプルから即時に状態分類、遷移一覧、監査項目を表示
- Evidence quality: 3/5 — 純粋ロジック18件を検証済み。実プロジェクト由来の状態機械との比較は未検証

仮説: 状態遷移をテキストから静的監査して結果をJSONに残せれば、ゲーム制作者が進行不能ルートと状態名の参照ミスを実装前に減らせる。

観測ループ: 状態遷移入力 → ルート監査 → 未到達・終了不能・行き止まりを確認 → JSON保存。CounterAPIのcomplete/startを主要指標にする。
