# Web Service Incubator

1時間ごとに小さな無料Webサービスを追加し、CounterAPIの匿名方向性カウンターで訪問・表示・利用開始・価値提供完了を見ながら継続／改善／停止を判断する公開実験室。

## 運用ルール

- 個人情報・秘密情報・PC/カメラ/位置情報を公開しない
- 外部AI/APIなど継続費がかかる機能は、無料枠とレート制限を確認するまで追加しない
- 各サービスに仮説、主要指標、公開日時を記録する
- 24時間未満の数字で成功判定しない
- 改善対象は利用開始率、完了率、再訪率を優先する
- 有料化は実利用が確認できたサービスだけ、あむの承認後に行う
